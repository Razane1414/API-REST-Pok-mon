## Overview

API-REST-Pok-mon is a powerful Node.js-based framework for building secure, scalable RESTful APIs centered around Pokémon data management. It provides a solid foundation for CRUD operations, user authentication, and database integration, enabling rapid development of data-driven applications.

**Why API-REST-Pok-mon?**

This project simplifies the process of creating a robust API with features tailored for Pokémon datasets. The core features include:

- 🛠️ **🔧 API Endpoints:** Comprehensive routes for creating, retrieving, updating, and deleting Pokémon records.
- 🚀 **🔑 Authentication:** JWT-based user login and secure access control to protect sensitive data.
- 💾 **Database Integration:** Sequelize ORM setup with initial data seeding for persistent storage.
- 🌐 **Middleware Setup:** Request logging, JSON parsing, favicon serving, and error handling for smooth server operation.
- 🎯 **Mock Data:** Ready-to-use Pokémon dataset for testing and development.
- 🔒 **Secure Data Management:** Role-based access and validation to ensure data integrity and security.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** JavaScript
- **Package Manager:** Npm

### Installation

Build API-REST-Pok-mon from the source and install dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/Razane1414/API-REST-Pok-mon
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd API-REST-Pok-mon
    ```

3. **Install the dependencies:**

**Using [npm](https://www.npmjs.com/):**

```sh
❯ npm install
```

### Usage

Run the project with:

**Using [npm](https://www.npmjs.com/):**

```sh
npm start
```

### Testing

Api-rest-pok-mon uses the {__test_framework__} test framework. Run the test suite with:

**Using [npm](https://www.npmjs.com/):**

```sh
npm test
```
